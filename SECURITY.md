# Security policy

Patch3Q handles vulnerability reports and proof-of-concept material. Do not file a public GitHub issue containing an unpatched vulnerability, exploit code, recipient vault, private key, or sensitive deployment detail.

For this hackathon build, contact the repository owner privately before sharing security-sensitive findings. Include only a minimal description in the first message and agree on an encrypted delivery method before sending technical evidence.

## Supported version

Only the latest commit on the default branch is supported during active development.

## Scope notes

QoreSeal is pre-1.0, the contracts are unaudited, and `MockFUSD` is a permissionless test token. Patch3Q is not production-ready and must not custody real bounty funds without independent review.
